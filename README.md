## Add your real photos

Create an `images` folder beside `index.html` and add five genuine personal photographs:

- `me.jpg` — your portrait
- `friends.jpg` — photo with friends
- `moment.jpg` — favourite moment
- `group.jpg` — group picture
- `another.jpg` — another personal photo

The HTML already references these filenames.

If your files use PNG instead, change the relevant `src` values in `index.html`.

Use genuine photographs for the assessment rather than stock or unrelated internet images.

## Run

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.
